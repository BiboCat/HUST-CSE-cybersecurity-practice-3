# 网络安全综合实践三

本仓库是华中科技大学网络空间安全学院课程《网络安全综合实践三》（2024级）的练习记录与学习笔记，包含各专题 Writeup、复现脚本、自制工具与知识点速查。

> ⚠️ **临时 README**：练习尚未全部完成，本文件只做目录索引与简要说明，全部做完后会替换为完整的正式版。

## 说明

- 每个专题按 `G1 ~ G4` 划分为 4 个题目（`安全补丁对比分析` 专题目前只做到 `G1`，`G2`/`G3` 仍为草稿）。
- 目录/文件以 `_` 开头（如 `_G4`）表示**该题尚未完成**，仅有草稿与初步分析。
- 所有内容仅用于个人课程学习与靶场练习，请勿用于未授权测试。
