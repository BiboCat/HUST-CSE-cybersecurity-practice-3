# 网络安全综合实践三

本仓库是华中科技大学网络空间安全学院课程《网络安全综合实践三》（2024级）的练习记录与学习笔记，包含各专题 Writeup、复现脚本、自制工具与知识点速查。

> ⚠️ **临时 README**：练习尚未全部完成（当前剩 `终端EDR绕过/_G4`、`安全补丁对比分析/_G4` 两题），本文件只做目录索引与简要说明，全部做完后会替换为完整的正式版。

## 说明

- 每个专题按 `G1 ~ G4` 划分为 4 个题目，共 8 个专题 32 题，已完成 30 题。
- 目录/文件以 `_` 开头（如 `_G4`）表示**该题尚未完成**，仅有草稿与初步分析。
- 所有内容仅用于个人课程学习与靶场练习，请勿用于未授权测试。

> - 每个 `G*` 目录内放该题正文（Markdown）、配套截图目录（`<题目>-images/`、`images/` 或与正文同名的目录）与 exp 脚本，此处不再展开。
> - 以 `_` 开头的目录表示该题尚未完成；目前仅剩 `终端EDR绕过/_G4`（syscall 层审计绕过，仅初步分析）与 `安全补丁对比分析/_G4`（空占位）。
> - 远程 exp 脚本（`DEP`、`GS`、`安全补丁对比分析`）需在文件内填写 token 靶机与 flag 靶机的 `IP`/`PORT`，随后直接 `python exp.py` 运行；
>   `安全补丁对比分析-G3` 的 exp 依赖 pwntools，需先 `pip install pwntools`。
> - `软件逆向静态分析-G3/G4` 的 `get_flag/get_flag.py` 与 `G1/exp/xor_aa.py` 为纯离线脚本（逆 S 盒 / key 已硬编码），无需连接靶机，直接 `python get_flag.py` 即可。
> - `软件逆向静态分析/G2/rc4tool/` 是配套的 RC4 加解密工具，自带 README，可独立使用，例如：
>   `python rc4tool.py dec --key-hex <KEY> --in-hex <CIPHER>`。
